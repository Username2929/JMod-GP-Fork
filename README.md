# Contributing

If you want to be a contributor, contact the owner of GP on Discord for further details. 

# Setup for Contribution

You must have a github account, first. You can make one for free.
Please make sure you have actual coding knowledge, do not vibecode everything. AI use is permitted for learning certain functions for when you're stuck, but not for generating entire copy & paste codeblocks. 
Any type of destruction to the repo will get you punished ingame, in the discord, and your contributor permissions revoked. This includes the following but is not limited to;

Deleting all files
Destruction of repository folders
Other acts of destruction that result in loss of data


Thank you.
